# Methods

This repository accompanies the manuscript **“From Surface Warming to Vertical Phytoplankton Reorganization in the North Pacific Subtropical Gyre.”**

The complete data-processing and analytical methods are described in **Supplementary Table S1** of the manuscript’s *Supplementary Information*. They include regional averaging; satellite and Argo data processing; estimates of phytoplankton carbon, apparent oxygen utilization (AOU), mixed-layer depth (MLD), and ocean heat content (OHC); and trend and breakpoint analyses.

In brief, phytoplankton carbon is estimated from particulate backscattering, AOU is calculated as oxygen at saturation minus observed oxygen, MLD is derived from physical Argo density profiles, and OHC is calculated from Argo Conservative Temperature. Breakpoint results and statistical diagnostics are reported in **Supplementary Table S6**.

For the code and outputs associated with each Table S1 method, see [COVERAGE.md](COVERAGE.md). For input data, setup, and MATLAB commands, see [README.md](README.md).
